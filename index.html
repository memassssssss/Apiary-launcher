АРХИТЕКТУРА И ТЕХНИЧЕСКИЕ РЕШЕНИЯ

Как устроен лаунчер под капотом и почему он работает стабильно

Изоляция сред выполнения

В отличие от стандартных лаунчеров, складывающих все в общий %appdata%/.minecraft, Apiary Launcher монтирует для каждого профиля собственный изолированный каталог --gameDir. Конфигурации, моды, шейдеры и карты версий 1.12.2, 1.20.1 и 1.21.1 физически не пересекаются и не затирают настройки друг друга.

Безопасный менеджмент токенов

Авторизация Microsoft реализована через защищенный модуль с использованием библиотеки Electron safeStorage. Токены доступа шифруются системным криптографическим хранилищем Windows DPAPI перед записью в локальный конфиг и никогда не передаются на сторонние серверы.

Собственный сетевой стек

Все запросы к Modrinth, CurseForge и Adoptium API обрабатываются через Chromium Network Service (модуль net.fetch). Это гарантирует автоматическую поддержку сжатия gzip/brotli, корректную работу через системные прокси и отсутствие зависаний сетевых сокетов при поиске контента.

Отказоустойчивый запуск

Дочерний процесс JVM запускается с контролем кодов выхода. Если игра завершается сбоем, лаунчер считывает последние строки буфера, определяет первопричину (нехватка памяти, сбой видеодрайвера OpenGL, битые Mixin-классы) и выводит понятную диагностику на русском языке.

ИНТЕРАКТИВНЫЙ КАЛЬКУЛЯТОР JVM

Настройте параметры вашей системы для расчета оптимальной конфигурации лаунчера

РЕКОМЕНДУЕМАЯ ПАМЯТЬ (-Xmx) 6.0 ГБ
ТРЕБУЕМАЯ JAVA JRE Java 21 LTS
АЛГОРИТМ СБОРЩИКА МУСОРА ZGC Generational
ГЕНЕРИРУЕМАЯ СТРОКА АРГУМЕНТОВ: -XX:+UseZGC -XX:+ZGenerational -Xmx6144M -Xms1024M -XX:+AlwaysPreTouch

СТРУКТУРА КАТАЛОГОВ КЛИЕНТА

Нажимайте на папки дерева, чтобы посмотреть их назначение и способ изоляции

.apiary-launcher/
├── runtime/ (Изолированные JRE 8, 17, 21)
├── instances/ (Все сборки и профили)
│ └── [Имя сборки]/minecraft/
│ ├── mods/ (Модификации сборки)
│ ├── shaderpacks/ (Шейдерные пакеты)
│ ├── resourcepacks/ (Текстур-паки)
│ └── screenshots/ (Снимки экрана F2)
└── versions/ (Манифесты ядер и загрузчиков)
Каталог instances/

Каждая сборка создается в собственном изолированном каталоге. Моды, шейдеры и конфиги одной версии никогда не смешиваются с файлами других сборок.

ПОРЯДОК УСТАНОВКИ

Три простых шага для начала игры

01

Скачайте установщик

Загрузите актуальный исполняемый файл Setup версии 2.1.0 с официального репозитория GitHub.

02

Произведите установку

Запустите инсталлятор и выберите удобную директорию на SSD-накопителе для быстрой загрузки ассетов.

03

Выберите сборку

Задайте никнейм, выберите нужную версию Minecraft и нажмите кнопку запуска. Лаунчер автоматически подготовит окружение.

Предупреждение Windows SmartScreen

При первом запуске операционная система Windows может показать синее окно защиты. Это стандартное поведение фильтра SmartScreen для новых исполняемых файлов без платного корпоративного сертификата подписи кода.

Инструкция по запуску:
  1. Нажмите на текстовую ссылку «Подробнее» (More info) в окне предупреждения.
  2. Нажмите появившуюся кнопку «Выполнить в любом случае» (Run anyway).
