APIARY LAUNCHER

Официальный кастомный лаунчер для комфортной игры на сервере Apiary SMP. Быстрая установка сборок, встроенное управление Java и мягкий Soft Sage дизайн.

СКАЧАТЬ ДЛЯ WINDOWS Windows 10 / 11 (x64) • .exe

⚡ Автоподключение

Все актуальные моды и сборки сервера обновляются и скачиваются автоматически в один клик.

☕ Smart Java

Лаунчер сам подбирает правильную версию Java под каждую сборку Minecraft или позволяет указать свою.

🌿 Open Source

Код лаунчера полностью открыт на GitHub. Вы можете проверить безопасность каждого файла лично.

🛡️ Предупреждение SmartScreen

При первом запуске Windows может показать синее окно защиты. Это происходит потому, что у независимых инди-приложений нет дорогого коммерческого цифрового сертификата издателя.

Как запустить:
  1. Нажмите синюю ссылку «Подробнее» в окне Windows.
  2. Нажмите появившуюся кнопку «Выполнить в любом случае».
