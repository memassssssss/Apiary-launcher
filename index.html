APIARY LAUNCHER

ТЕХНИЧЕСКИЙ СТЕК ПРОЕКТА

На каких библиотеках и технологиях построен Apiary Launcher

FRAMEWORK

Electron & Node.js

Кроссплатформенная среда с разделением на Main и Renderer процессы для стабильной фоновой работы без зависаний UI.

API INTEGRATION

Modrinth REST API v2

Асинхронная выгрузка описаний, версий, скриншотов и зависимостей модов с автоматической сортировкой по загрузчику.

CORE LAUNCHER

Minecraft-Launcher-Core

Надежное ядро генерации манифестов версий, загрузки нативных библиотек Mojang и спавна защищенного процесса JVM.

SECURITY

Node Crypto & DPAPI

Аппаратная привязка шифрования ключей авторизации к учетной записи текущего пользователя Windows.

PERFORMANCE

Chromium Net Service

Пакетная закачка тяжелых архивов модов и текстур в несколько потоков с поддержкой алгоритма сжатия Brotli.

RUNTIME

Adoptium Temurin JDK

Чистые портативные среды Java (HotSpot), не требующие системной установки и не трогающие системный PATH.

ИНТЕРАКТИВНЫЙ КАЛЬКУЛЯТОР JVM

Настройте параметры вашей системы для расчета оптимальной конфигурации лаунчера

РЕКОМЕНДУЕМАЯ ПАМЯТЬ (-Xmx) 6.0 ГБ
ТРЕБУЕМАЯ JAVA JRE Java 21 LTS
АЛГОРИТМ СБОРЩИКА МУСОРА ZGC Generational
ГЕНЕРИРУЕМАЯ СТРОКА АРГУМЕНТОВ: -XX:+UseZGC -XX:+ZGenerational -Xmx6144M -Xms1024M -XX:+AlwaysPreTouch

СТРУКТУРА КАТАЛОГОВ КЛИЕНТА

Нажимайте на папки дерева, чтобы посмотреть их назначение и способ изоляции

.apiary-launcher/
├── runtime/ (Изолированные JRE 8, 17, 21)
├── instances/ (Все сборки и профили)
│ └── [Имя сборки]/minecraft/
│ ├── mods/ (Модификации сборки)
│ ├── shaderpacks/ (Шейдерные пакеты)
│ ├── resourcepacks/ (Текстур-паки)
│ └── screenshots/ (Снимки экрана F2)
└── versions/ (Манифесты ядер и загрузчиков)
Каталог instances/

Каждая сборка создается в собственном изолированном каталоге. Моды, шейдеры и конфиги одной версии никогда не смешиваются с файлами других сборок.

ПОРЯДОК УСТАНОВКИ

Три простых шага для начала игры на Apiary SMP

01

Скачайте установщик

Загрузите актуальный исполняемый файл Setup версии 2.1.0 с официального репозитория GitHub.

02

Произведите установку

Запустите инсталлятор и выберите удобную директорию на SSD-накопителе для быстрой загрузки ассетов.

03

Выберите сборку

Задайте никнейм, выберите нужную версию Minecraft и нажмите кнопку запуска. Лаунчер автоматически подготовит окружение.

Предупреждение Windows SmartScreen

При первом запуске операционная система Windows может показать синее окно защиты. Это стандартное поведение фильтра SmartScreen для новых исполняемых файлов без дорогостоящего корпоративного сертификата подписи кода.

Инструкция по первому запуску:
  1. Нажмите на текстовую ссылку «Подробнее» (More info) в синем окне предупреждения.
  2. Нажмите появившуюся внизу кнопку «Выполнить в любом случае» (Run anyway).
